# C-Utils

A C/C++ library to make C/C++ more easy to program, working with C90 and C++98 standards or higher.

Compatible with:

- [x] Windows.
- [x] Linux.
- [x] Mac OS.
- [x] Android (NDK/Termux).
- [x] IOS.
